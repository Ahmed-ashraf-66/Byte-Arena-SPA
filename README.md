# ByteArena 🎮

ByteArena is a modern Single Page Application (SPA) built with Vanilla JavaScript and Tailwind CSS v4, allowing users to discover, explore, and learn about free-to-play games using the FreeToGame API.

## ✨ Features
- **Home Page**: Features top games, new releases, and category navigation.
- **All Games**: Comprehensive game catalog with interactive search, filtering, and sorting.
- **Trending**: Switch between New Releases and Top Popular games.
- **Surprise Me**: A fun feature to pick a random game instantly.
- **Game Details**: Deep dive into game descriptions, system requirements, screenshots, and similar recommendations.
- **Saved Games**: Client-side persistence using LocalStorage to save favorite games.

## 🛠️ Technologies Used
- **HTML5 & CSS3**
- **Tailwind CSS v4** (`@tailwindcss/cli`)
- **Vanilla JavaScript (ES6+ Modules)**
- **Tabler Icons**
- **FreeToGame API**
